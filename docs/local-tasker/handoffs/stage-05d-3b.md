## 6. Database objects
- NEW `local_booking_cancellations` (booking_id unique, request_id unique, reason_key, note <= 300, coordinator_id, cancelled_at). Immutable, RLS on, admin read only, no browser grants. Trigger `lbc_audit`: one `local_booking_events` row (`cancelled`) and one `local_tasker_audit` row.
- NEW `local_booking_problem_reports` (booking_id, dispute_id unique, request_id unique, coordinator_id, category). Same protections. Trigger `lbpr_audit` (`problem_reported`).
- NEW internal helpers `_local_booking_cancel_block(p_booking)` and `_local_booking_report_block(p_booking)` (service_role only): the reason something cannot be done now, or null.
- NEW `local_booking_cancel(p_booking, p_request_id, p_reason, p_note)`. Reasons: `customer_asked`, `customer_unreachable`, `tasker_unavailable`, `tasker_no_show`, `other` (needs a note of 3+ characters). Order of refusals: not the active managing coordinator (`not_found`); bad input (`bad_input`); retry returns the earlier result; then `booking_closed`, `dispute_open`, `wrong_status` (disputed or awaiting_confirmation), `money_held` (snapshot paid > 0 when the snapshot answers, payment_status paid/released, escrow held, a captured gift card hold, or any paid request on the booking's rooms), `payment_started` (a processing request). Effects: unpaid (`pending`, `failed`) payment requests of the booking's rooms -> `cancelled`; pending `job_requests` -> `expired`; `bookings.status` -> `cancelled`; the record; `_job_event(... 'cancelled', 'Job cancelled by your StreetTasker coordinator', reason label - note)` (the customer gets the chat line and a notification). Works when the booking has no Job Room yet.
- NEW `local_booking_open_problem(p_booking, p_request_id, p_category, p_reason)`. Categories as `open_job_dispute`; reason 10 to 1000 characters. Refusals: `booking_closed`, `dispute_open` (already reported or status disputed), `too_many` (3 in 24 hours, same rule as `open_job_dispute`). Opens the Job Room if there is none (`_local_booking_thread`), inserts the real `job_disputes` row (`opened_by` = the Local Tasker's user, role `tasker`; the real trigger freezes the booking), a `dispute_events` row (`opened`, actor = the coordinator), the record, and notifies the customer.
- NEW `local_booking_withdraw_problem(p_booking, p_dispute)`: only a report opened through this function, only while `open` (`not_open` once under review or decided); a second call is harmless. Adds a `dispute_events` row (`withdrawn`), a booking event and an audit row.
- NEW `local_booking_closeout(p_booking)` (coordinator read): `can_cancel` / `cancel_blocked`, `can_report` / `report_blocked`, `cancellation`, `problems` (id, category, status, opened_at, can_withdraw).
- NOT touched: `lt_status`, `payment_status`, `payment_intents`, `escrow_payments`, wallets, release code, paid or processing payment requests, Edge Functions, `job_cancel`, `open_job_dispute`, `support_resolve_dispute`, any 5D-1/5D-2/5D-3a function.
