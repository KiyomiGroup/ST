6. **Suspend and restore.** Edge Function order: check (as caller) -> Auth ban or unban (service role, server only) -> record (as caller). If the record fails the ban is undone and the message says so; if the undo also fails the message tells the person to check Supabase, Authentication, Users. **Ban limits:** it stops new sign-ins and token refreshes; a session already open can keep working until its access token expires (Supabase default up to 1 hour). Restore lifts the ban. Bookings, disputes, reviews and refunds are never touched, and nothing here moves money.

A customer is a `users` row whose `role` is `customer` or whose `roles` contain `customer`. No approval is needed (spec: unless D-A10 says otherwise); every suspend, restore and refusal is in `admin_audit_log`.
