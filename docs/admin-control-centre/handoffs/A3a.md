# Stage A3a: Admin frame and sign-in (2026-11-08)

A3 was too large for one session, so it is split: **A3a** (this one: design rule, frame, sign-in, headers), **A3b** (My Profile and the guard in `js/auth.js`), **A3c** (Help and two-step verification set-up). A3b and A3c are described in `00-PLAN.md`.

1. **Objective.** The first admin pages: a sign-in, a frame with a permission-aware menu, and a safe "No access" for everyone who is not an admin.
2. **Done.** Wrote the pages and ran them in a headless browser (Chromium through Playwright) against a **fake Supabase** (a stand-in script, not the real service). Checked at 390, 820 and 1280px: no sideways scroll, no script errors, menu drawer opens and closes (button and Escape), icon sidebar at tablet width. Fake-server cases that behaved correctly: signed out goes to sign-in with a safe redirect; non-admin sees "No access"; two-step needed message; server error shows Retry; wrong password and "valid login but not an admin" show the **same** message and the second is signed out; unsafe `redirect` values fall back to the Overview; no `localStorage` key is written. **Nothing was run against the real Supabase, so the real sign-in has not been tried.**
